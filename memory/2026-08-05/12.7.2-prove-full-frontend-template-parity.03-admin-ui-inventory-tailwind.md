# Inventário admin UI permite classes utilitárias Tailwind

Ajustado `scripts/check-admin-ui-inventory.mjs` para rejeitar apenas classes no padrão BEM (`__`/`--`) não registradas, em vez de rejeitar qualquer `className` fora da allowlist. Isso permite o uso normal de utilitários Tailwind nas surfaces admin e mantém a flag de dívida técnica para BEM locais e controles raw.

## Evidência

- [[scripts/check-admin-ui-inventory.mjs]] — *regex BEM para `local_variants`*.
- [[scripts/check-admin-ui-inventory.test.ts]] — *caso de teste para utilitários Tailwind*.
