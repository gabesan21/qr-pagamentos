# Catalog template remodel

Remodeled `/catalog`, `/catalog/products/new`, `/catalog/products/[id]` and `/catalog/categories` to the Epoch 12 template using `DataDirectory`, `LocalizedFieldGroup`, `SectionCard`, `ImageField`, `StatusBadge` and `MoneyText`. Preserved exact-decimal price handling, dirty-field omission for optional fields, image staging via `POST /products/images`, currency gating, and terminal archival. Added local catalog primitives in `catalog-fields.tsx` and bilingual dictionary keys.
