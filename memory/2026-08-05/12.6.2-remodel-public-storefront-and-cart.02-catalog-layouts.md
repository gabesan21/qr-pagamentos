# Catálogo nos layouts boxed e table

O catálogo agrupado foi recomposto com `Card` para `boxed` e `Table` para `table`, mantendo o valor livre como primeiro item quando `standalonePayments` está ativo. Preços passaram a usar `MoneyText`, quantidades usam `QuantityStepper`, e o campo de valor livre usa `CustomAmountField` com `FieldLabel`, `FieldDescription` e `FieldError`. A lista legada `products` não voltou a renderizar.
