# Brand and application asset contract

- `template-asset-sources.ts` is the closed source/provenance register for the
  17 supplied project assets. Their immutable reference bytes remain under
  `docs/template/`; runtime code never imports that tree.
- `geometry.ts` is the only canonical QR glyph geometry. Never duplicate or
  redraw it in a page, component, generated lockup, or favicon routine.
- `wordmark.outlines.svg` is the reviewed canonical Sora 700 wordmark derived
  from pinned licensed bytes. Static outputs embed its paths and never contain
  live text or a host, local, or remote font dependency.
- `brand-identity.tsx` owns the four closed inline identities: mark-only,
  product lockup, compact role-shell lockup, and merchant fallback. Inline
  identities inherit one semantic foreground and never branch by theme ID.
- A mark beside visible identity text is decorative. A standalone meaningful
  mark receives one caller-supplied localized accessible name; never add an SVG
  `title` that creates a duplicate announcement.
- `assets.manifest.json`, `public/brand/**`, `public/application-assets/**`, and
  `src/app/favicon.ico` are generated by `pnpm brand:generate`; never edit their
  bytes directly. The public application namespace is application-owned
  presentation, not merchant media.
- `pnpm brand:check` fails closed on source or output byte/hash drift, incomplete
  provenance, unsafe SVG syntax, unknown files, duplicate bytes, dimension or
  theme-ID drift, and incoherent 16/32/48 favicon frames.
- Static positive/reversed lockups are only for contexts that cannot inherit a
  semantic UI color. The six swatches preview exact stored token themes; neither
  identity nor component code branches on a swatch or theme ID.
- Avatar, product, and store fallbacks identify an application-owned absence
  state. They never imply merchant ownership or create upload capability,
  storage identifiers, quota, or media lifecycle state.
