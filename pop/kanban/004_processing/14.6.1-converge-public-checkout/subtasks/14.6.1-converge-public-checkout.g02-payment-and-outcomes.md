## Contrato de execução

- **Public API (fixed here so F03 can wire it without renegotiation):** one exported view component taking `dictionary`, the closed client state (the V1 order-state vocabulary plus the V2 `RESERVED`/`CREATING` attempt states), optional `pixCopyPaste`/`pixQrCodeUrl`, the already-formatted total and optional currency label, the merchant name and optional merchant identity node, a `pollFailed` flag and the two callbacks `onRetryPoll` and `onStartOver`. Every label arrives through `dictionary`; the module owns no fetch, no timer and no locale logic.
- **State coverage:** `RESERVED`/`CREATING`/`CREATED` are the waiting treatment (never an error, never a destructive badge); `PENDING` and `INDETERMINATE` keep the live view, `INDETERMINATE` adding its own confirming-with-the-bank line; `CONFIRMED`, `REFUNDED`, `REJECTED`, `CANCELLED` and `EXPIRED` each get their own composition with title, body and the state badge. The three failures offer start-over; refunded is neutral; confirmed is the success view.
- **Badges and tone:** use `ProviderStateBadge` with caller-supplied localized labels — never a second badge style, never a tone re-derived in this file, never colour as the only carrier of meaning (icon or text always accompanies it).
- **QR and copy:** render `QrDisplay` with `payload` (the PIX copy-paste string) so the SVG is generated client-side on the white frame, passing the merchant identity node as the centre-cut when one exists; while the payload has not arrived, render the pending treatment with its localized busy label. The PIX code uses `CopyField` `variant="compact"` with exactly one feedback channel — the component already announces its own state, so do not add a second live region.
- **Success view:** no new image asset. The closed brand/application inventory is generated and hash-checked, so compose the success marker from the existing owned primitives (badge plus icon plus heading); the terminal-failure views may reuse the already-installed `unavailable` illustration through `EmptyState` if it fits the composition.
- **Absent by contract:** this module renders no order reference, no expiry countdown, no payer recap built from data the public projection does not carry, and no provider detail. If the template composition seems to require one, report it — do not invent a field.
- Anything real but outside the card's "O quê / Por quê" is a follow-up proposal in your report — never a new criterion or a new front.
- **Saber parar:** no máximo 2 tentativas quando a falha for de ambiente; na segunda, registre `ambiente`, reporte a reclassificação para `verify: user` e siga.
- Dependência ou entrada ausente/incompatível → responder `BLOCKED` ao agente principal com evidência; nunca implementar ou simular a dependência.
