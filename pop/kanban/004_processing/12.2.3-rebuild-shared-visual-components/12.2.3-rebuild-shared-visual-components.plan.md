# Plan — [[12.2.3-rebuild-shared-visual-components]]

- **Stage:** 002_planning · **Owner:** agent planner

## Objective and expected result

- **Objective:** rebuild the production-owned primitive and role-neutral composition vocabulary for all 20 template components assigned to 12.2.3, preserving the existing server-first application and data-directory contracts without duplicate visual owners.
- **Observable result:** later route tasks can import one accessible, token-driven owner for every reachable shared responsibility; all 187 assigned parity obligations have a production disposition, all 49 unreachable generated UI sources stay excluded, and current consumers remain behaviorally and visually sound.

## Strategy and defense

Treat the parity graph as the closed presentation inventory, not as source to transplant. Reconcile `button`/`checkbox`, add only the focused official primitives required to realize reachable `input-otp`, `switch`, modal/confirmation, tabs, avatar/monogram, empty, pagination, and toast responsibilities, and record an insufficiency finding plus states for every addition. The official CLI must be used read-only before registry changes; the planner's `info/docs` attempt was DNS-blocked and changed no files.
Collapse template `DataTable`, `FilterBar`, and total-count pagination into the existing `DataDirectory` owner: native GET filters, keyset links, bounded page sizes, narrow facts, and wide table remain server-authoritative. Realize template Modal/Toast/Tabs/Avatar through official accessible primitives rather than hand-rolled focus, overlay, or provider behavior. Shared compositions accept localized/redacted/formatted values and never import mocks, auth, stores, business services, or exact-money logic.
Keep static compositions server-renderable and isolate clipboard, OTP, switch, dialogs, tabs, localized-field selection, and toast behavior in narrow client files with minimal serializable props. Fresh visual evidence reruns current `/design-system` and directory consumers at the exact task HEAD; 12.2.4 exclusively owns adding the complete specimen matrix, so this task edits no route, shell, or specimen source.
