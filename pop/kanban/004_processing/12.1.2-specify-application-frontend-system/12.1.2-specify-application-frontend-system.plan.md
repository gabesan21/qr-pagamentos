# Plan — [[12.1.2-specify-application-frontend-system]]

- **Stage:** 002_planning · **Owner:** agent planner

## Objective and expected result

- **Objective:** Establish the supplied template as the complete application presentation/feedback contract without changing production UI or any business/security behavior.
- **Observable result:** A canonical application-wide spec and implementation-ready `DESIGN.md` bind exact template composition, states, responsive behavior, assets, accessibility, anti-drift, and parity evidence for all later Epoch 12 tasks.

## Strategy

Use the immutable parity manifest as visual authority and the existing specs/DOX as behavioral authority. First activate the planning draft and reciprocal supersession boundary; then rewrite `DESIGN.md` as the concise executable memory consumed by later implementation tasks. Preserve the fixed Next.js stack, server-first boundaries, six stored theme IDs, `pt-BR`/`en`, and every existing owner/security/exact-money invariant.

Template logo/illustrations are authorized presentation targets, but their runtime bytes remain gated by the existing deterministic provenance pipeline in 12.2.2. Typography targets Sora/Inter/IBM Plex Mono only through pinned licensed self-hosted sources; remote loading is never a fallback. Missing storefront/standalone designs use the parity contract's authorized extrapolation.

## Affected areas

- `pop/specs/application-frontend-system.md` — new durable application-wide contract (created in 002 as `draft`/`planned`).
- `pop/specs/administrative-design-system.md` — predecessor receives reciprocal supersession only when the new contract activates.
- `DESIGN.md` — replacement implementation-ready design memory; no production source changes.

## Risks and abort conditions

- **Risk:** Exact visual language is diluted into generic guidance — mitigation: enumerate numeric laws and cite parity IDs/source hashes as the exact remainder.
- **Risk:** Template mocks overwrite durable behavior — mitigation: explicit business/security precedence and no backend/API ownership.
- **Risk:** Spec lifecycle overstates delivery — mitigation: planning stays `draft`/`planned`; activation records `partial` reality until later Epoch 12 UI tasks conform.
- **Abort if:** a required production font/asset cannot obtain pinned license/provenance, or parity demands a stack/security/behavioral change — report the exact lane; do not substitute or broaden this task.
