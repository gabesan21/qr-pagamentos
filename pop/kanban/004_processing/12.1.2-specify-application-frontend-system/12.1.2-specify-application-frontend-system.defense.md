# Plan defense — [[12.1.2-specify-application-frontend-system]]

- **Stage:** 002_planning · **Owner:** agent planner

## Contestable decisions

| # | Decision | Adopted choice | Rejected alternative | Why | What would falsify it |
|---|---|---|---|---|---|
| 1 | Visual authority | Hash-bound template parity records govern presentation; current specs govern behavior | Copy template source/runtime wholesale | Exact parity and existing security/runtime contracts both remain enforceable | A parity requirement cannot be expressed in the fixed stack without behavioral change |
| 2 | Contract lifecycle | New application-wide spec supersedes the Epoch 1 visual spec; delivered UI remains partial until later tasks | Rewrite history or mark the remodel implemented now | The old scope conflicts and this task ships contracts, not UI | The predecessor contains a still-authoritative rule absent from the new spec |
| 3 | Fonts | Exact Sora/Inter/IBM Plex Mono roles through pinned licensed self-hosted sources | Google Fonts runtime or substitute typography | Typography is parity-critical and external requests are forbidden | No licensable, pinnable production source exists for a required family |
| 4 | Identity/assets | Supplied assets are approved targets but enter runtime only through deterministic provenance in 12.2.2 | Immediate raw copy or retention of old visual identity as final | Honors exact template intent without bypassing safe-SVG/hash/accessibility/merchant boundaries | Provenance cannot be established or the target violates accessibility/ownership constraints |
| 5 | Missing public pages | Extrapolate `/store/[slug]` and `/store/[slug]/pay` from the same system | Invent another style or reuse the invalid slug shortcut | User authorized extrapolation and parity inventory owns these gaps | A dedicated authorized template surface appears before implementation |
| 6 | Execution topology | Activate spec, then rewrite `DESIGN.md` in sequential ownership | One broad writer or parallel edits | Keeps lifecycle and executable memory independently reviewable with a real dependency | The active spec cannot fully constrain the design-memory rewrite |
