# 14.4.2-converge-admin-dashboard-and-directories — Converge admin dashboard and directories


- **Origem:** [[pop/roadmap/14-template-fidelity-convergence|Phase 14.4]]
- **Plano:** [[14.4.2-converge-admin-dashboard-and-directories.plan]] · **Aprovação:** [[14.4.2-converge-admin-dashboard-and-directories.approval]] · **Verificação:** [[14.4.2-converge-admin-dashboard-and-directories.verify]]

## O quê

`/admin`, `/admin/orders`, `/admin/orders/**`, `/admin/payment-links` and `/admin/payment-links/v2/[id]` reproduce the template compositions: segmented period control, 5/4/3 grid, active-users delta chip, merchant-filtered drill-downs, per-card skeletons and error+retry; orders directory with source/provider-state/local-outcome/merchant/pair filters and a single unified V1+V2 table; links directory with identifier CopyField, amount/products and created columns plus merchant/pair filters; link detail with public URL, associated-orders list and lifecycle badges; unavailable states as illustrations; domain badge families adopted.

## Por quê

The admin family audit rates these pages medium-low: missing filters and columns, lost grid spans, dead drill-downs and BEM compositions keep administrators far from the template's designed operations views.
