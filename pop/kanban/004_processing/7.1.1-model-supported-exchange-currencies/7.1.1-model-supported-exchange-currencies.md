# 7.1.1-model-supported-exchange-currencies — Model supported exchange currencies

- **Phase:** [[roadmap/7-merchant-settings-and-catalog|Phase 7.1]]
- **Plan:** [[7.1.1-model-supported-exchange-currencies.plan]] · **Approval:** [[7.1.1-model-supported-exchange-currencies.approval]] · **Verification:** [[7.1.1-model-supported-exchange-currencies.verify]]

## What

Model a dynamic, admin-registered exchange-currency catalog: runtime-managed ISO 4217 codes and Nautt UUID mappings (never build-time or inferred), activation behavior, historical references, and safe selection defaults. When no active mapping exists, the UI prohibits dependent actions and the backend returns well-defined errors.

## Why

Products, stores, payment links, standalone payments, filters, and administrator settings need one canonical currency meaning that grows dynamically as the administrator registers provider mappings.
