# Plan — [[12.2.1-rebuild-template-tokens-and-typography]]

- **Stage:** 002_planning · **Owner:** agent planner

## Objective and expected result

- **Objective:** replace the superseded token/font source with the exact template foundation as a validated DTCG 2025.10 graph and deterministic CSS projection, including a real specimen consumer for every typography role.
- **Observable result:** all application CSS resolves the six fixed themes and Inter/Sora/IBM Plex Mono roles locally; real specimen IDs and money use the numeric role, stale family copy is absent, and exact audit values, accessible semantics, stable aliases, and fresh visual proof remain bound.

## Strategy

Pin the required OFL Fontsource packages and preserve their licenses/provenance before consuming them. Retain `@fontsource-variable/ibm-plex-sans` only as transitional brand provenance for 12.2.2, with no runtime or CSS use in this task. Rebuild the canonical source as separate primitive, semantic, component, theme, and motion inputs resolved after merge, then generate both target semantic variables and value-free compatibility aliases for unmigrated consumers. Exact template bytes remain audit primitives; the rendered layer uses the six fixed tertiary projections and validates every consumed foreground/background pair. Do not transplant the template's local-storage theme provider: persisted production identifiers and server-owned selection remain authoritative.

## Affected areas

- `package.json`, `pnpm-lock.yaml`, `src/design-system/fonts/**` — pinned local font supply and provenance.
- `src/design-system/**`, `scripts/*design-token*`, `src/app/globals.css` — DTCG graph, validation and generated projection.
- `src/app/design-system/page.tsx`, evidence tests/verifier, `artifacts/design-system/**` — real numeric consumers, language-neutral type metadata and run-bound proof.

## Gaps and preflight

- **Preflight:** install the exact pinned Fontsource packages with pnpm and inspect each installed `package.json`, `LICENSE`, requested Latin CSS entrypoint, and lock integrity before importing it. Abort F01 if any Sora, Inter, or IBM Plex Mono package lacks OFL-1.1, required 400/500/600 weight (plus Sora 700), Portuguese/English glyph coverage, or local WOFF2 output.
- The repository cache contains only the legacy IBM Plex Sans package. Keep it installed but UI-inert until 12.2.2 migrates the brand manifest; dependency retrieval for the three target families remains an execution concern, not a planning blocker.

## Risks and abort conditions

- **Risk:** exact audit colors fail accessible use — preserve their bytes and derive/map only semantic on-colors; tests bind both layers.
- **Risk:** compatibility aliases become a second system — aliases contain no raw values and resolve only target semantic/component variables.
- **Abort if:** a required font cannot pass the F01 provenance preflight, or the fixed contract cannot be represented without weakening the stored-theme/runtime boundary; report `blocked` with the failing package/path or contract conflict.
