# Front F01 — File-backed mail config and public origin — [[11.1.1-build-self-hosted-password-reset]]

- **Deliverable:** Validated loader that reads mail and public-origin configuration from files (`/run/secrets/*`) in the container, keeping env-var fallback for dev/test; secrets mounted in `compose.yaml` and staged by the installer/prepare-secrets script.
- **Scope:** configuration loader, compose secrets, staging.
- **Responsible:** agent.
- **Owns:** `src/auth/mail-config.ts`, `src/auth/mail-config.test.ts`, `compose.yaml`, `pop/scripts/container-prepare-secrets.mjs`, `install/install.sh`, `install/.env.example`, `.env.example`, `.env.compose.example`.
- **May read:** `container/lib.mjs`, `src/auth/identity.ts`, `README.md`, `docs/production-runbook.md`.
- **Must not edit:** `src/auth/mail-sender.ts`, `src/auth/admin-password-reset.ts`, reset routes/pages.

## Execution contract

- The loader accepts `SMTP_HOST_FILE`, `SMTP_PORT_FILE`, `SMTP_USER_FILE`, `SMTP_PASSWORD_FILE`, `SMTP_FROM_FILE`, `SMTP_TLS_MODE_FILE`, `PUBLIC_ORIGIN_FILE` pointing to files; when absent, falls back to the current env vars.
- Existing validation (present host, port 1-65535, closed TLS mode, canonical from, HTTPS origin without credentials/fragment) is preserved.
- `compose.yaml` adds secrets `smtp_host`, `smtp_port`, `smtp_user`, `smtp_password`, `smtp_from`, `smtp_tls_mode`, `public_origin` mounted under `/run/secrets/`.
- `pop/scripts/container-prepare-secrets.mjs` and `install/install.sh` stage these files with the same permissions as other secrets.
- Env templates document the new values.
