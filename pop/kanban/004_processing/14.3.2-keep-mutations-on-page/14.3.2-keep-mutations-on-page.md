# 14.3.2-keep-mutations-on-page — Keep mutations on page


- **Origem:** [[pop/roadmap/14-template-fidelity-convergence|Phase 14.3]]
- **Plano:** [[14.3.2-keep-mutations-on-page.plan]] · **Aprovação:** [[14.3.2-keep-mutations-on-page.approval]] · **Verificação:** [[14.3.2-keep-mutations-on-page.verify]]

## O quê

Order comments and local outcomes, payment-link edits/lifecycle actions, and the remaining catalog/settings/profile mutations redirect back to the page that submitted them with a toast notice (via the notice bridge) and preserve typed input on failure; the profile password change no longer logs the user out.

## Por quê

Post-mutation redirects still land on directories or `/`, losing the detail context the template keeps, and several failures drop the user's input.
