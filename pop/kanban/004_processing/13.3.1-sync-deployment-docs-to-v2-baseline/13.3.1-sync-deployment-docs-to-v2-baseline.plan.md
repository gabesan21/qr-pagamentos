(2) `docs/release-evidence.md` is a frozen ledger bound to `5d0f1a7` (2026-07-21); its PASS rows were proven against a tree that has since been rebased, and it must not be rewritten. (3) `pop/PROJECT.md:13-17` is dated 2026-07-31, omits epochs 12–15, and calls CSP "deferred" although the 2026-09-23 decision accepts it permanently. (4) `README.md:208` still instructs the operator to open `/pt-BR` and `/en`, contradicting `README.md:42` (locale-prefixed routes return 404), and `README.md:212` points at `researches/nautt-finance/raw/` instead of `pop/researches/nautt-finance/raw/`.

They stay verbatim and the script is not touched. The accepted caveats (no CSP/no middleware, process-local limiter therefore single-instance, console-sink JSON logs with no external alerting) get one canonical home — the runbook's operating boundary, which already carries the limiter caveat; `PROJECT.md` points to the decision note instead of repeating them.
