# H-16.1 — Live BRL storefront amount mask

## Approved scope

Make the standalone storefront amount field render a BRL cash mask during
typing: visible `R$` prefix, dot grouping, and comma decimals. Ordinary digit
entry uses cents semantics (`1000` becomes `R$ 10,00`); selection, backspace,
delete, and valid localized pastes retain a stable caret. A valid explicitly
pasted/received BRL value keeps up to six exact fractional digits without
numeric coercion or rounding. Non-BRL input and all backend/payment behavior
remain unchanged.

- [x] BRL digit entry, replacement, backspace, delete, select-all, and valid
  paste update the masked display and the canonical decimal string correctly.
- [x] Malformed or ambiguous grouping stays invalid and does not produce a
  canonical amount; exact six-decimal pasted and received values remain exact.
- [x] Non-BRL amount input stays on its existing unmasked path.
- [x] Focused jsdom interaction tests pass with the pinned Node/pnpm runtime.
