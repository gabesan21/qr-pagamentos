# Defesa do plano — 12.4.1-remodel-administrator-dashboard

- **Etapa:** 002_planning · **Responsável:** agent planejador

## Decisões contestáveis

| # | Decisão | Escolha adotada | Alternativa rejeitada | Por quê | O que a falsificaria |
|---|---------|-----------------|------------------------|---------|----------------------|
| 1 | Motor do period switcher | Segmented control visual feito com links server-rendered (`/admin?period=...`) | Client `SegmentedControl` com `framer-motion` e `useState` | O projeto é Next.js App Router server-first; adicionar client boundary e animação só para o switcher quebra o contrato atual de URL canônica e exige nova dependência. | Métricas mostrando que usuários não conseguem trocar de período sem JS, ou requisito explícito de animação. |
| 2 | Biblioteca de animação | Barras de progresso e hover states com CSS transitions | Instalar `framer-motion` para replicar o template | `framer-motion` não está no projeto e adicioná-lo só para este dashboard é dívida desnecessária; reduced motion já é regra. | Teste de design system exigindo motion idêntica ao template ou auditoria reprovando CSS transitions. |
| 3 | Link do leaderboard de lojistas | `/admin/accounts` (spec administrativa) | `/admin/orders?merchant=...` do template | A fundação administrativa fixa que owner attribution navega para o diretório de contas; o filtro por merchant não existe no app. | Spec alterada permitindo drill-down por merchant nas ordens. |
| 4 | Título da página | Manter `WorkspaceHeading` com `shellAdminDashboardTitle` | Substituir por título local "Overview" do template | Reutiliza o shell entregue em `12.3.1` e mantém consistência visual em todas as páginas administrativas. | Requisito de que o dashboard deva ter título/caption distintos do shell. |
