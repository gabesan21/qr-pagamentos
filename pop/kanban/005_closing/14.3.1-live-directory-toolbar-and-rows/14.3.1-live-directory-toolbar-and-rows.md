# 14.3.1-live-directory-toolbar-and-rows — Live directory toolbar and rows


- **Origem:** [[pop/roadmap/14-template-fidelity-convergence|Phase 14.3]]
- **Plano:** [[14.3.1-live-directory-toolbar-and-rows.plan]] · **Aprovação:** [[14.3.1-live-directory-toolbar-and-rows.approval]] · **Verificação:** [[14.3.1-live-directory-toolbar-and-rows.verify]]

## O quê

`DataDirectory` behaves like the template's `DataTable`/`FilterBar` on top of the server-rendered data: search (debounced), filters and page size update the URL on change with a pending skeleton and no Apply button, active-filter chips render on every directory with localized labels, rows are clickable (row link + explicit action), invalid params are ignored with an info toast instead of an error card, and `src/data-directory/AGENTS.md` is revised to allow this owner behaviour.

## Por quê

Every list is a GET form with Apply/Reset and prev/next cursors, chips never render on catalog/categories, and invalid URLs replace the table with an error card — the single largest interaction gap against the template across admin and merchant.
