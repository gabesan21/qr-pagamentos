# Plan — [[12.1.1-establish-template-parity-contract]]

- **Stage:** 002_planning · **Owner:** agent planner

## Objective and expected result
- **Objective:** Establish one exhaustive, machine-checkable contract mapping the supplied template authority to every current frontend surface and to objective parity evidence.
- **Observable result:** Later Epoch 12 tasks can identify every route, reachable component, authored class occurrence, applicable state, interaction, locale, theme, asset, and viewport obligation without rereading or interpreting the template.

## Strategy

First ingest the complete supplied `docs/template/**` tree and root `FRONTEND_TEMPLATE_PROMPT.md` byte-for-byte as the versioned reference. Build the contract manifest from its reachable `docs/template/app/src/App.tsx` graph and the current Next.js page/loading/error route inventory. Each obligation records its source, target, disposition, later owner, and evidence target. Bind the manifest to source hashes and a deterministic validator so drift or an unmapped obligation fails closed.

Template presentation and interaction feedback are authoritative; current specs remain authoritative for authorization, data, security, precision, mutation, locale, and stored theme identifiers. Mock-only behavior never becomes a production requirement. `/store/[slug]` and `/store/[slug]/pay` use the user-authorized extrapolation disposition.

The evidence protocol uses the repository's pinned Playwright Chromium project, device scale 1, full-page PNGs, fixed `320x1000`, `375x1000`, `768x1000`, and `1440x1000` CSS viewports, deterministic fixtures/clock, local settled fonts, disabled animation/caret, and blocked external requests. Comparable pixels use threshold `0.1` and `maxDiffPixelRatio: 0.001`; any geometry, typography, content, state, focus, or overflow difference remains a failure regardless of ratio.

## Affected areas
- `docs/frontend-template-parity/**` — canonical manifest and concise human contract.
- `scripts/check-frontend-template-parity-contract.mjs`, `package.json` — deterministic completeness/drift gate.
- `docs/template/**`, `FRONTEND_TEMPLATE_PROMPT.md` — immutable supplied reference; `src/app/**` and shared frontend sources — read-only current inputs.
- `tsconfig.json`, `eslint.config.mjs` — production inventory boundaries for the reference-only template.

1. **Wave 1:** F03; then F01 against its committed reference.
2. **Wave 2:** F02 after F03 and the F01 schema/inventory stabilize.
3. **Re-entry delta:** F04 only, after the completed F03/F01/F02 commits.
4. **Integration:** Validate F04 ownership, run C8, then the aggregate `pnpm check`.

## Risks and abort conditions

- **Risk:** Generated but unused shadcn files inflate scope — mitigation: inventory only modules transitively reachable from `App.tsx`, while recording excluded generated inventory and rationale; production-tool exclusions name only the immutable reference root.
- **Risk:** Visual tolerance masks meaningful drift — mitigation: the ratio covers raster noise only; named semantic/geometry differences fail independently.
- **Abort if:** a referenced template source/asset is unreadable, source graph cannot be deterministically resolved, or parity would weaken an existing application contract; report `BLOCKED` with the exact path/edge.
