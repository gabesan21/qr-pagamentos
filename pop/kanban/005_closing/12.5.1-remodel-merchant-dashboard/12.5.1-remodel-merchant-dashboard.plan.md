# Plano — 12.5.1-remodel-merchant-dashboard

> Produced by the planning agent. Persisted by orchestrator.

- **Etapa:** 002_planning · **Responsável:** agent planejador

## Objetivo e resultado esperado

- **Objetivo:** Remodel `src/app/(merchant)/page.tsx` and `dashboard.tsx` to match the template dashboard composition and shared component system.
- **Resultado observável:** Owner landing page uses StatCard, MoneyText, EmptyState, SimpleTabs, and template grids; period, currency, storefront link, and analytics behavior are preserved.

## Estratégia

Reuse the delivered shared UI inventory. Keep server rendering and the merchant-analytics service untouched; map existing `MerchantAnalyticsView` fields onto the template layout. Preserve period negotiation, exact-decimal currency formatting, and storefront gating. Update loading skeleton and unit tests to match.

## Áreas afetadas

- `src/app/(merchant)/page.tsx` — header, period tablist, storefront link, notices.
- `src/app/(merchant)/dashboard.tsx` — cards, stats, funnel, lists.
- `src/app/(merchant)/loading.tsx` — template-aligned skeleton.
- `src/i18n/dictionaries/merchant-dashboard/{en,pt-BR}.ts` — new labels.
- `src/app/(merchant)/page.test.tsx`, optional `dashboard.test.tsx` — updated assertions.
- `src/app/globals.css` — remove obsolete `.merchant-dashboard*` rules once unused.

## Riscos e condições de aborto

- **Risco:** Template expects counts not present in `MerchantAnalyticsView` (orders in period, total links, product counts). Mitigação: map available fields (funnel attempts, confirmed/local sales, active links, best sellers, recent orders); do not extend analytics in this task.
- **Abortar se:** A required shared component is missing or its API differs from the reference; verify `src/components/ui/inventory.json` and component sources.
