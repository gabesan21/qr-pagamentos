# M-9.1 scoped implementation delta

The worktree began with a carried dirty baseline and no committed snapshot of
that baseline exists. This is therefore a scoped reviewer manifest, not a
mechanically subtractable Git diff.

## Canonical contract

- `src/design-system/tokens/{themes,semantic,components}.tokens.json` adds
  control density and directory-width roles.
- `scripts/generate-design-tokens.mjs` projects those roles; generated
  `src/app/globals.css` contains the resulting variables and fine-pointer
  desktop override.
- `src/components/ui/{button,input,native-select,textarea,field,label}.tsx`
  consumes the generated contract. Button preserves `sm` and adds/uses
  `row`, `icon-row`, `inline`, `lg`, and `quiet-destructive` roles.

## Consumers and enforcement

- Shared consumer migrations are limited to the compact directory, account
  row action, authentication/password affordances, admin settings theme and
  language selection, catalog category action, link editor, checkout privacy
  action, and Nautt visibility action.
- `scripts/check-design-tokens.mjs` uses the installed TypeScript AST to find
  control imports (including aliases), native controls, static class strings,
  composition calls, template pieces, and responsive/state variants. It
  permits only documented native structural controls and the exact compact
  directory `min-[360px]` media breakpoint.
- `scripts/design-tokens.test.ts`,
  `src/components/ui/control-density.test.tsx`, and
  `src/components/ui/primitive-inventory.test.tsx` contain the related
  projection, contrast, API, and negative-guard regressions.
- The existing `font: inherit` control reset now belongs to `@layer base`, so
  Tailwind control text utilities retain the generated mobile 16px role. The
  shell compact header uses the documented 640px grid boundary, with a static
  regression in `src/app-shell/app-shell.test.tsx`.

## Documentation and limitation

- `DESIGN.md`, `pop/specs/application-frontend-system.md`,
  `src/components/ui/AGENTS.md`, and `src/data-directory/AGENTS.md` record
  the contract and the narrow responsive exception.
- The required pinned shadcn CLI preflight was attempted before primitive
  edits. `info` could not open its local database and `docs`/`add --dry-run`
  could not resolve `ui.shadcn.com` (`EAI_AGAIN`), so no registry source was
  fetched or overwritten.
