# 14.5.3-converge-catalog-settings-profile — Converge catalog, settings and profile


- **Origem:** [[pop/roadmap/14-template-fidelity-convergence|Phase 14.5]]
- **Plano:** [[14.5.3-converge-catalog-settings-profile.plan]] · **Aprovação:** [[14.5.3-converge-catalog-settings-profile.approval]] · **Verificação:** [[14.5.3-converge-catalog-settings-profile.verify]]

## O quê

`/catalog/**`, `/settings` and `/profile` reproduce the template: flat product form with active/inactive control on create, default currency pre-selected, `ImageUploader` with drag-and-drop staging, sticky preview, archived neutral badge and `product-fallback` image; categories with inline edit for every row (inactive included), template deactivation dialogs; settings with theme swatch grid, layout segmented control, color picker plus hex, `ImageUploader` for the logo, store-enabled switch with confirmation in the identity section, default-currency clear button, Nautt validate/replace for an active credential with reset confirmation, checkout policy as four radio cards; profile with the template TOTP enrollment order (QR + manual secret first, confirm, then recovery codes with copy-all and download), regenerate confirmation, enrolled-since date and continuous password meter.

## Por quê

The catalog/settings/profile audit rates these pages low to medium-low: nested cards, native selects and file inputs, restructured TOTP flow and missing template controls keep merchants far from the designed operations surface.
