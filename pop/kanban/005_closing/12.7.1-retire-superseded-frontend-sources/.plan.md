# 12.7.1-retire-superseded-frontend-sources — plano

## Objetivo
Remover com segurança fontes frontend obsoletas após a remodel da Epoch 12: stubs de rotas locale-prefixed, componentes não importados, regras CSS mortas e assets não referenciados, preservando contratos de negócio, schemas, rotas API ativas e assets gerenciados pelo brand contract.

## Áreas de varredura
1. Rotas App Router (`src/app/`) — stubs `[lang]/` e duplicatas legado.
2. Componentes de página/auxiliares (`src/app/**`) — imports não resolvidos.
3. CSS (`src/app/globals.css`, `src/app-shell/app-shell.css`) — classes/variáveis mortas.
4. Assets estáticos (`public/`) — referências em JSX/CSS/manifests/scripts.
5. Testes de contrato (`src/app/routes.test.ts`) — dependem dos stubs removidos.

## Estratégia de identificação
- `git grep` por imports/paths e por strings de classe/asset.
- Análise de conteúdo: stubs retornam `notFound()`/`404`; componentes sem `import` em `src/`/`tests/`.
- Verificação cruzada com `src/brand/template-asset-sources.ts`, `assets.manifest.json`, `scripts/generate-brand-assets.mjs` e `scripts/brand-contract.mjs` para assets gerados.
- Exclusão explícita de V1/V2 de negócio, rotas API ativas (`/api/*`, `/payment-links`, `/orders`, etc.) e schemas.

## Candidatos à remoção

### A. Stubs locale-prefixed
Remover todo `src/app/[lang]/` (9 arquivos, incluindo testes). Todas as rotas retornam `404`/`notFound()` e nenhum runtime aponta para elas.

### B. Componentes não importados
- `src/app/(merchant)/catalog/dirty-select.tsx`
- `src/app/(merchant)/catalog/product-image-field.tsx`
- `src/app/(merchant)/links/share-copy.tsx`

### C. Regras CSS mortas
Em `src/app/globals.css`:
- ~23 classes custom sem uso (ex: `.admin-catalog-list`, `.checkout-skeleton`, `.storefront-empty`).
- ~26 variáveis CSS definidas mas não consumidas (ex: `--action-primary-hover`, `--color-feedback-*-soft`).
- Variáveis usadas mas não definidas: `--control-height`, `--space-7`, `--type-compact-heading`, `--type-label`.

Em `src/app-shell/app-shell.css`:
- Remover `.app-shell__account-sign-out` (não usada).
- Adicionar regra para `.app-shell__sign-out` ou ajustar markup.

### D. Assets legado do template Next.js
`public/globe.svg`, `public/next.svg`, `public/vercel.svg`, `public/window.svg` — sem referências.

### E. Assets gerados sem referência em runtime
`public/application-assets/auth-texture.svg`, `checkout-success.svg`, `store-logo-fallback.svg`. Requer atualização de:
`src/brand/template-asset-sources.ts`, `src/brand/assets.manifest.json`, `scripts/generate-brand-assets.mjs`, `scripts/brand-contract.mjs`.

### F. Teste de contrato a reescrever
`src/app/routes.test.ts` deve passar a assertir que `/pt-BR/login`, `/en/admin` e `/pt-BR/design-system` não são resolvidas, em vez de importar os stubs.

## Riscos reais
1. `routes.test.ts` perde o objeto de teste se não for reescrito antes da remoção.
2. `pnpm brand:check`/`pnpm brand:generate` falham se assets gerados forem removidos sem atualizar `template-asset-sources.ts`, `assets.manifest.json`, `generate-brand-assets.mjs` e `brand-contract.mjs`.
3. Variáveis/classes CSS aparentemente mortas podem ser usadas por scripts de design-system evidence; verificar `tests/design-system.evidence.spec.ts` e `scripts/check-design-tokens.mjs`.
4. Não confundir com rotas/API V1/V2 de negócio, que continuam ativas.
5. `public/file.svg` é usado como fixture em testes — não remover.

## Baseline observado
`pnpm check` falha no estado atual com erro pré-existente em `src/components/ui/input-otp.test.tsx` (`ReferenceError: window is not defined`). A task não deve introduzir novas falhas; esse erro existente deve ser considerado no gate final.

## Critérios de verificação
- [ ] `pnpm typecheck` passa.
- [ ] `pnpm lint` passa (inclui `tokens:check`, `brand:check`, `fonts:check`, `check-design-tokens.mjs`, `eslint`).
- [ ] `pnpm test` passa (inclui `routes.test.ts` reescrito).
- [ ] `pnpm build` passa.
- [ ] `pnpm check` (agregado) passa.
- [ ] `git grep` não encontra referências aos caminhos removidos em `src/`/`tests/`/`scripts/`.
- [ ] Nenhum arquivo de contrato de negócio, schema, rota API ativa ou asset referenciado foi removido.

## Subtasks
1. **Remover stubs `[lang]` e reescrever contrato** — apagar `src/app/[lang]/` e reescrever `src/app/routes.test.ts` para `404` implícito.
2. **Remover componentes órfãos** — `dirty-select.tsx`, `product-image-field.tsx`, `share-copy.tsx`.
3. **Limpar CSS morto** — remover classes/variáveis não usadas de `globals.css` e ajustar `app-shell.css`.
4. **Limpar assets** — remover SVGs legado do template; remover assets gerados sem referência e atualizar brand contract.
5. **Verificação final** — rodar `pnpm check` e corrigir regressões.
