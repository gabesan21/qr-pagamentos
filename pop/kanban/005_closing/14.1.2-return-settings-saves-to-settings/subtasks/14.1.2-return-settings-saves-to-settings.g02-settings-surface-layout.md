## Contrato de execução

- **Layout:** `settings-surface__*` gains CSS in `globals.css`, built from existing tokens with no raw value — one column by default, two columns from `64rem` with the nav column at `calc(var(--space-12) * 4)`, `--space-6` gaps, the nav sticky and the sections' `scroll-margin-block-start` at `calc(var(--top-bar-height) + var(--space-6))`, links at `min-height: var(--control-min-height)`, a `:focus-visible` semantic ring, and an active state carried by background/start border/weight beyond color. Below the breakpoint the nav is hidden, as in the template.
- **Scroll-spy:** an `IntersectionObserver` in the existing client component marks the current link with `aria-current`; without JS the anchors keep working. Introduce no smooth scrolling.
- **Headings:** each section keeps `<section id aria-labelledby>` + `h2`/`p`; the inner `CardHeader` repeating that same title/description goes. Section ids and `aria-labelledby` are untouchable (F01 points at them).
- **Notices:** the storefront, checkout-policy and language notices move into their own section, keeping today's copy keys and the same `role`/`aria-live`. The Nautt notice stays where it is.
- **Copy:** one new key in the `settings` domain for the page description (and, if needed, for the language section's description), in both locales, with identical key sets in `en` and `pt-BR`; no merchant settings file references `adminLanguageDescription` any more.
