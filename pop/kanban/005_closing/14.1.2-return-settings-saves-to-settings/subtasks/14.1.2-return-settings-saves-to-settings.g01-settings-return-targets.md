## Contrato de execução

- The `/storefront`, `/checkout-policy` and `/storefront/logo` targets are **server-side literals** built inside the route file itself: nothing coming from the client names a path. The anchors are the ones pinned in the plan.
- The new module resolves the `/language-preference` return: it reads `Referer`, requires the host expected by the same rule `src/app/origin-guard.ts` uses (first `X-Forwarded-Host`, else `Host`), discards query and fragment, and returns **one literal of the closed allowlist** — `/settings` or `/`. An absent, unparseable, foreign-scheme, foreign-host or non-allowlisted referer returns the `/` fallback. The allowlist is closed by plan decision (only those two pages render the `language` notice); widening it is a plan change, not an execution one.
- The `#settings-language` fragment accompanies only the `/settings` return.
- Introduce no hidden `returnTo` field in any form: the shell belongs to another task and must not be edited.
