# Plano — [[14.2.4-build-domain-badge-and-inventory-parity]]

- **Etapa:** 002_planning · **Papel:** `pop-planner` (separado da execução)

## Objetivo e resultado esperado

- **Objetivo:** bring `src/components/ui/` to template parity — domain badge families over one owned tone map, an owned `ImageUploader`, and the numeric/identity gaps (compact `CopyField`, 48px `Monogram`, payload-generating `QrDisplay`, `StatCard` sparkline, `MoneyText` pair suffix) — and make the executable inventory, its check script, the DOX and the spec record the result.
- **Resultado observável:** a page author importing from `@/components/ui` gets tone, uploader and QR generation for free; `check-shared-ui-inventory.mjs` and `design-system:source-check` stay green with the additions declared.

## Estratégia

Owners only. **No page is migrated** (adoption is 14.4–14.6) and every current public API stays backwards compatible, so today's call sites compile untouched; the domain families and new props are strictly additive. Labels stay with callers as localized `labels` records (the `CopyField` pattern), so shared UI imports no dictionary and no domain enum — the families own **tone and shape**, which is the drift the audit found.

Three findings constrain the shape and are not negotiable:

1. **The uploader cannot become a parity owner.** `docs/frontend-template-parity/obligations.ndjson:1525` records `ImageUploader.tsx` as `excluded-unreachable-generated-ui`, and both `check-shared-ui-inventory.mjs` (20 owners, one obligation each, no excluded source in ownership) and `check-design-system-coverage.mjs` (coverage ids must equal `inventory.owners`) fail closed if it enters `owners`. It is declared instead in a new **`localAdditions`** section — one owner, import path, public props/states, one-line insufficiency: the "genuinely new component" clause of the frontend spec, whose sentence "No upload component is admitted by this inventory" is the durable contract F04 amends.
2. **`primitive-inventory.test.tsx` asserts the `.tsx` file set equals primitives ∪ the 13 `inventory.owners` compositions.** A 14th file breaks it. That test is the executable form of the inventory contract this task extends, so F04 — and only F04 — updates that single assertion to read `localAdditions`. Deliberate, narrow exception to the read-only rule on tests; no other test is touched.
3. **Only one new file is admitted.** `qr-display.tsx` itself becomes `"use client"` and generates the QR instead of adding a second module, reusing the pinned `qrcode@^1.5.4` with the precedent in `src/app/profile/totp-qr-code.tsx` (`QRCode.toString(payload, { type: "svg" })`). `qrcode.react` is rejected: it adds a dependency for what the pinned one already does, and `inventory.requiredDependencies` is a closed checked list. The library emits its black-on-white bytes at runtime, so the source carries no raw color; the forced-light frame uses Tailwind `bg-white`, a utility rather than a raw value, because QR modules need a fixed light quiet zone in all six themes.

## Áreas afetadas

- `src/components/ui/` — six owners gain additive API, one new file (`image-uploader.tsx`), `qr-display.tsx` gains a client boundary, `inventory.json` gains a section; plus `check-shared-ui-inventory.mjs`, `AGENTS.md`, `DESIGN.md` and the frontend spec as the contract record.
- **Read-only:** `src/app/**` (must not change), `src/media/**`, `src/brand/**`, `docs/**`, `package.json`.

## Ordem e paralelismo

1. **Onda 1:** F01, F02 e F03 em paralelo — write sets disjuntos, nenhuma depende do resultado da outra (F03 só lê a API preservada de `StatusBadge`). **Onda 2:** F04, que precisa dos paths e da API pública finais. **Integração:** o principal valida ownership com `pop_check_scope.py` e confere os critérios `agent`.

## Riscos e condições de aborto

- **Risco:** arquivo novo em `src/components/ui/` quebra `primitive-inventory.test.tsx` — mitigação: F04 estende a asserção junto com `localAdditions`; nenhuma outra frente toca teste. Editar os owners invalida os hashes de fonte de `design-system:evidence:verify` — regeneração é cara e roda uma vez na phase (C11), não é defeito desta task.
- **Abortar se:** cumprir C06 exigir alterar `docs/frontend-template-parity/**` ou `package.json` — sinalizar `blocked: true` citando o registro de exclusão.
