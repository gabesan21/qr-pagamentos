## Execution contract

- Use official primitives for focus trap/restoration, titles, tab semantics and toast stacking; do not reproduce the template's hand-rolled overlay/provider.
- Keep clipboard work in the click handler with pending/copied/failure/retry live feedback; no deprecated DOM-copy fallback or hidden payload disclosure.
- Localized fields accept the exact two already-localized labels/values and associated errors; no route locale, dictionary or domain type import.
- Confirmation failure remains open, pending disables duplicate submission, allowed dismissal restores focus, and destructive meaning is non-color.
- Pass only minimal serializable props into each client boundary; use functional state updates and module-level child components.
- Reduced motion must collapse non-essential transitions without removing state, focus or feedback.
