# M-7.1-shrink-root-agents-contract — Plano

## Escopo

Reduzir o contrato raiz `AGENTS.md` ao teto de ~60 linhas do DOX, movendo detalhes operacionais genéricos para upstream ou para contratos-filho/specs.

## Passos

1. **Auditar a raiz:** medir seções e identificar o que é delta do projeto vs. prosa genérica do Workflow/DOX.
2. **Substituir a seção `Processo DOX`** por um link para `[[pop/WORKFLOW]]`; manter apenas a frase que define a árvore DOX como contrato vinculante.
3. **Substituir o `Application contract`** por um índice conciso de domínios (identidade/segurança, administração, catálogo/links, checkout/pedidos, storefront, mídia, observabilidade), cada um com link para a spec aplicável e para o AGENTS.md filho quando existir.
4. **Adicionar `prisma/AGENTS.md`** ao `DOX index`.
5. **Verificar:** rodar `python3 pop/scripts/pop_validate.py --scope pop` e garantir que `AGENTS.md` fique abaixo de ~80 linhas.
6. **Documentar:** atualizar o card e a modification, escrever memory.

## Riscos

- Perder uma restrição do Application contract durante a condensação → mitigação: manter todo item como link/índice; nenhum comportamento de código muda.

## Critérios de aceite

- `wc -l AGENTS.md` ≤ 80 (respeitando a exceção de índice de árvore grande).
- A seção genérica de processo DOX desaparece; o processo é linkado.
- `prisma/AGENTS.md` aparece no DOX index.
- Nenhum teste ou check falha.
