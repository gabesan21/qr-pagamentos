## Contrato de execução

- **Period control:** a route-local client component, not a new shared primitive — compose the owned `Tabs`/`TabsList` (default pill variant) so the anti-drift inventory gains nothing. The current period arrives as a prop from the server page; selecting one commits `?period=<id>` through `useRouter().replace` inside a transition, keeps every other query pair, and shows the pending state. Keep a `<noscript>` fallback with the three plain links so the closed `today`/`7d`/`30d` set still works without JavaScript, and keep the pinned `7d` default for absent or unknown values (no redirect).
- **Grid:** replace `admin-dashboard__row/col` with `grid gap-4 lg:grid-cols-12` and `lg:col-span-{5,4,3}` for orders/sales/funnel, the 3-up users row and the 4-up inventory row on plain responsive utilities. Every remaining `.admin-dashboard__*` class in the dashboard files goes; then delete the whole rules block from `globals.css` (it has no other consumer outside tests). Progress bars keep the existing literal width buckets — no inline style, no raw value.
- **Delta chip:** the active-users `StatCard` renders `trend` with a label built only from counts the projection already returns. Never add a field to `AdminAnalyticsView` and never render a sparkline: neither the projection nor the template's `DashboardStats` carries a series — record the gap in the report for F04.
- **States:** `loading.tsx` renders the dashboard skeleton (the exported one, currently dead) after its geometry matches the final 3 / 5-4-3 / 4 / 2 rows; `error.tsx` becomes the template's inline strip — one line of message plus a retry that calls `reset()` — instead of the stacked destructive alert. Keep the existing notice/toast bridge untouched.
- **Drill-down:** each top-merchant row links to `/admin/orders?filter.merchant=<encoded username>`; keep the rank, monogram, localized non-color deleted badge and the confirmed metrics, and keep the existing empty states.
- Every new or changed user-facing string lives in `admin-dashboard/en.ts` and `admin-dashboard/pt-BR.ts` under the same key.
