1. **Promote the primitive.** `catalog-draft.tsx` is a pure client util with no catalog semantics; move it to `src/app/form-draft.tsx`, rename the storage prefix to a form-neutral one, move its test alongside, and update the three catalog import sites. Keep the exported names and the `CatalogDraftGuard` behaviour identical apart from the neutral name — three other fronts consume it in wave 2, so its shape is a contract, not a suggestion.
2. **Verify categories, do not rebuild them.** `/product-categories` already returns to `/catalog/categories` and the page already mounts `CategoryNotice`. Confirm the closed notice set covers `create|edit|deactivate|conflict|failed` and that the draft guard still covers the inline create and the row-edit inputs after the move. Any genuine gap is a one-line note in the result, not a redesign.
3. **Write the delivered contract.** Rewrite, in place and without restating implementation:
   - `administrative-foundation.md` — the merchant mutation redirect sentence (currently naming `/settings?…#<section>` only) gains the order, link, profile and Nautt destinations; the profile rotation sentence replaces "expires authentication, and returns `/login?password=changed`" with the delivered rotation: every session revoked atomically, one fresh session issued for the same actor, and the merchant left signed in on `/profile?password=changed`.
   - `catalog-and-payment-links.md` — the link mutation destination moves from `/links?payment-links-v2=<outcome>` to the link's own detail (create to the created link), with failures returning to the submitting form; the legacy V1 create/revoke returns to `/links` instead of `/`.
   - `checkout-and-order-lifecycle.md` — comment append/edit and set-outcome return to `/orders/v2/<id>` with the closed notice.
   - `DESIGN.md` — one rule next to the `ToastViewport` block: a mutation returns to the page that submitted it, with the destination derived server-side from the route param or the submitted `action`/`id`, never from a client-supplied path.

The prose describes the contract the wave-2 fronts must satisfy; do not invent a destination this file does not name.
