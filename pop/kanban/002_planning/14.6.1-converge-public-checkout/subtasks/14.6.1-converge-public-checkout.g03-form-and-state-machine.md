## Contrato de execução

- **Frozen export:** `createPollingController` keeps living in `src/app/pay/[identifier]/public-checkout-form.tsx` with the same name, signature and behavior, because `src/app/store/[slug]/pay/standalone-payment-experience.tsx` imports it from that path and is out of scope. Moving, renaming or reshaping it fails this front.
- **State machine:** an attempt is created once and survives typing. Field edits update values and clear that field's error only — they never clear attempt, payment or capability. Once an attempt exists the buyer sees the payment phase instead of the form; returning to the form happens only through the explicit start-over action, which resets the attempt and mints a fresh idempotency key. The existing retry of the *same* attempt (same key, same customer) stays available where the current code offers it, so idempotent replay is preserved.
- **Validation:** required-field behavior stays; format checks are added client-side for e-mail, CPF (mask plus check digits) and CEP (mask plus shape), with numeric `inputMode` on the masked fields and one specific message per failure kind. On submit, the first invalid field is scrolled into view and focused, and its control keeps `aria-invalid` paired with the field's `data-invalid`. The masked value must still reach the server in a shape the pinned server normalization accepts — the server contract does not change, so verify the accepted grammar in the spec before choosing what to submit.
- **Submit label:** the button names the exact total by substituting the server-provided decimal string (and the display currency code when the era has one) into the dictionary key. Never `Number`, `parseFloat` or `Intl` money math.
- **Polling:** cadence, backoff, visibility pause and the opaque `404` treatment stay exactly as delivered; only the moment the retry affordance appears changes — first failure, not third. Terminal states stop polling as today.
- **Both adapters:** V1 and V2 differ only in their closed state union, their endpoint payload shape and their summary facts; everything else lives once in the controller. Do not merge their distinct state vocabularies into one loose union that accepts a state its era cannot return.
- **Never:** new fetch, new endpoint, changed request body, provider detail rendered, order or provider identifier displayed, link expiry or link type consumed. Missing public data is reported, never inferred.
- Anything real but outside the card's "O quê / Por quê" is a follow-up proposal in your report — never a new criterion or a new front.
- **Saber parar:** no máximo 2 tentativas quando a falha for de ambiente; na segunda, registre `ambiente`, reporte a reclassificação para `verify: user` e siga.
- Dependência ou entrada ausente/incompatível → responder `BLOCKED` ao agente principal com evidência; nunca implementar ou simular a dependência.
- Não alterar caminhos fora de `Owns`; necessidade nova volta ao agente principal.
