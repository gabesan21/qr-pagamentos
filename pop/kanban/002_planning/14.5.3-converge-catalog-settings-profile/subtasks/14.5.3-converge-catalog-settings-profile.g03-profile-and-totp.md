## Contrato de execução

- Read the template `ProfilePage.tsx` first; reproduce the section order, the three-step enrollment and the copy, never the mock verification rule, fixtures or framer-motion.
- The three sections stack in a single `max-w-3xl` column; the page stops depending on `.profile-workspace*` and `.profile-form__fieldset` (F04 deletes the rules afterwards, so leave no consumer behind).
- Identity: Save disabled until a field is dirty, inline `role="alert"` errors for empty username and malformed email, conflict recovery kept, and the `FormDraftGuard` behaviour and `expectedVersion` mirror unchanged.
- Password: continuous meter driven by the typed length (no quarter-step class ladder), inline errors for length and mismatch, current-password requirement kept; the route and its redirect stay untouched.
- TOTP enrollment order becomes QR + manual secret + confirm + codes: derive the secret from the `secret` parameter of the `provisioningUri` the unchanged enroll response already returns and present it with `CopyField`; keep the codes from the same response **in component state only** — never `sessionStorage`, `localStorage`, a cookie or a query — and reveal them only after a successful confirmation.
- Confirmation is submitted with `fetch` to the unchanged `/profile/totp/confirm` (same-origin, the same `currentPassword` and `code` fields) and branched on the `totp` parameter of the followed 303 target: `confirmed` advances to the codes step, `failed` renders the inline wrong-code error without leaving the modal, and an unreadable outcome falls back to the native reload. The form keeps its `action`/`method` so the `<noscript>` path still works; refresh the page state when the modal closes.
- Codes step offers copy-all and a client-side download (`Blob` + object URL, revoked after use) plus the saved checkbox and the close guard; the same composition serves the regenerate modal, which now opens only after a `ConfirmDialog`.
- Do not render an enrolled-since date: `getStatus` projects only `none|pending|active`; leave the finding for F04 instead of widening a service projection.
- Every new string lands in `src/i18n/dictionaries/profile/{en,pt-BR}.ts` with both locales in parity.
- **Saber parar:** no máximo 2 tentativas quando a falha for de ambiente; na segunda, registre `ambiente`, reporte a reclassificação para `verify: user` e siga. Nunca construa infraestrutura para verificar.
