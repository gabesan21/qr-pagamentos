## Decisões que restringem esta frente

- The page title is resolved from an inert route→label registry supplied by each role layout and matched with the existing `isActiveRoute` rule, in the shell's existing client boundary; the merchant registry adds `/profile`, and an unmatched route falls back to the dashboard label. The static `shellAdminEyebrow`/`shellMerchantEyebrow` strings stop being the title.
- The rail media query moves from `48rem` to the `lg` boundary (1024px), keeping the responsive `display` technique so only one navigation copy stays in the accessibility tree.
- The rail footer becomes monogram + username + role pill + caption. The duplicated rail sign-out button is removed because the account menu already owns Sign out for both roles, as `src/app-shell/AGENTS.md` requires; the mobile panel footer stays as it is.
- The storefront link is resolved in the merchant shell context through the existing owner-scoped storefront settings service and passed as an inert `{href, label}` only when the storefront is enabled and has a slug. The target is `/store/<slug>`; the template's `/pay/<slug>` shortcut is forbidden by `DESIGN.md`.
- Navigation labels adopt the template wording for payment links and catalog in both locales; the caption key is new. Keys, routes and the fixed five entries per role do not change.
