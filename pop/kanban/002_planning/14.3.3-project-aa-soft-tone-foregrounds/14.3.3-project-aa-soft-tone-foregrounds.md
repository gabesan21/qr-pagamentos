# 14.3.3-project-aa-soft-tone-foregrounds — Project AA on-soft foregrounds


- **Origem:** [[pop/roadmap/14-template-fidelity-convergence|Phase 14.3]]
- **Plano:** [[14.3.3-project-aa-soft-tone-foregrounds.plan]] · **Aprovação:** [[14.3.3-project-aa-soft-tone-foregrounds.approval]] · **Verificação:** [[14.3.3-project-aa-soft-tone-foregrounds.verify]]

## O quê

Every soft-tinted surface (`bg-<tone>-soft`) renders its text with an AA-projected on-soft foreground token derived by the spec's `k`-step method for success/warning/danger/info in all six themes; the tokens flow through the DTCG source, the generator, `@theme` utilities and every soft consumer (badge families first), and the design-system evidence spec passes again.

## Por quê

The 14.2.5 evidence run proved four soft pairs fail WCAG AA at 12px (pix-paper danger 4.21/info 4.40, cashier-daylight success 4.41/warning 4.41); the spec makes AA at the rendered layer an objective gate, so the design-system evidence stays red until the projection exists.
