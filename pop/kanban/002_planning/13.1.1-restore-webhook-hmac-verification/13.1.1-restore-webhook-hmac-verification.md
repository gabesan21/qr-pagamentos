# 13.1.1-restore-webhook-hmac-verification — Restore webhook HMAC verification

- **Origem:** [[pop/roadmap/13-pre-production-hardening|Phase 13.1]]
- **Plano:** [[13.1.1-restore-webhook-hmac-verification.plan]] · **Aprovação:** [[13.1.1-restore-webhook-hmac-verification.approval]] · **Verificação:** [[13.1.1-restore-webhook-hmac-verification.verify]]

## O quê

Reverse the M-5.1 beta seam in `src/integrations/nautt/webhook-intake.ts` and `webhook-runtime.ts`: restore the raw-body HMAC signature gate with `loadActiveWebhookSecrets` + `verifyWebhookOwner` before any parsing, return empty no-store `401` for missing, malformed or unmatched signatures, remove the `resolveOwner` dependency, delete `webhook-intake-beta.test.ts` and convert the beta-acceptance pins in `webhook-intake.test.ts` back to `401` rejections. Add a redacted rejection log (delivery UUID, event, reason; never body, signature or secret) so a production mismatch is diagnosable. Webhook URL registration and `NAUTT_API_BASE_URL` untouched; no local webhook delivery test.

## Por quê

Production release is blocked by the open question of 2026-07-25: beta intake is unauthenticated, and the documented 2026-07-17 dispatcher contract is already implemented in `webhook-signature.ts`.
