# 15.1.1-remove-v1-application-surfaces — Remove V1 application surfaces

- **Origem:** [[pop/roadmap/15-v2-only-pix-integrity-and-explicit-checkout|Phase 15.1]]
- **Plano:** [[15.1.1-remove-v1-application-surfaces.plan]] · **Aprovação:** [[15.1.1-remove-v1-application-surfaces.approval]] · **Verificação:** [[15.1.1-remove-v1-application-surfaces.verify]]

## O quê

Delete every V1-only module, route, page, DTO branch, dictionary key and test named in the review findings (checkout/presentation/status services, `payment-link-order`, `order-view`, `src/auth/payment-link.ts`, `POST /payment-links`, `public-checkout-form.tsx`, `legacy-links.tsx`, both `legacy-order-table.tsx`, `/orders/[id]`, `/admin/orders/[id]`, `order-views.tsx`). `/pay/[identifier]`, the checkout and status API routes, `/orders`, `/admin/orders` and `/links` resolve Commerce V2 only, and no import of a V1 module remains anywhere in `src/`.

## Por quê

V1 was never a product (decision 1 of 2026-09-22); keeping it doubles every checkout/order surface and blocks the PIX and explicit-checkout fixes that follow.
