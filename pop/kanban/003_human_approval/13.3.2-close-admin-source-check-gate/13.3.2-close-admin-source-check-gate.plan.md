# Plano — [[13.3.2-close-admin-source-check-gate]]

- **Etapa:** 002_planning · **Papel:** `pop-planner` (separado da execução)

## Objetivo e resultado esperado

- **Objetivo:** make `pnpm admin:source-check` exit 0 across `src/app-shell/**`, `src/app/admin/**`, `src/app/(merchant)/**` and `src/app/language-preference/**`, with no behavior, authorization, copy or dictionary change.
- **Resultado observável:** the script prints `ADMIN_UI_SOURCE_OK raw_controls=0 adapter_imports=0 inline_styles=0 local_variants=0` and exits 0; no route file and no owned primitive changed.

## Estratégia

**Read-measured footprint (planner, by grep + AST-rule reading; the gate was not run).** Three of the four counters are already clean: every raw `<input>` in the scanned tree is a literal `type="hidden"` or `className="sr-only"` bridge already exempt (`admin/**` 12 hits, `(merchant)/**` 11 hits, `app-shell/**` and `language-preference/**` zero); no `@/app/ui` import and no `cva` import exist; the single `style=` (`src/app/admin/accounts/[id]/page.tsx:193`) is already allow-listed. **The whole red gate is `local_variants` (~50 findings), and every one of them contradicts a sanctioned contract** — the card's explicit exemption route, not the composition route:

- **~37 in `src/app-shell/**`** (`app-shell.tsx` 10, `shell-navigation.tsx` 23, `shell-theme-picker.tsx` 5, minus 19 already-allow-listed literals) are BEM chrome of `app-shell.css` — the one sanctioned route-neutral BEM stylesheet (DESIGN.md "BEM retirement (14.7.1)" :517-518; `src/app-shell/AGENTS.md:44-46`). Recorded as a stale allow list since 14.4.1 (`pop/notes/references/2026-09-09-epoch-14-report.md:37`), never as a defect.
- **13 in `admin/**` + `(merchant)/**`** are Tailwind arbitrary values carrying a design token (`text-[length:var(--type-title)]`, `max-w-[var(--layout-max)]`, `scroll-mt-[calc(var(--top-bar-height)+…)]`, `bg-[var(--storefront-accent)]`). `var(--token)` is the sanctioned token channel (`scripts/check-design-tokens.mjs:7,32-38`) and `max-w-[var(--layout-max)]` is a preserved exception of the 15.4.1 closed map — the `--[a-z]` regex is simply imprecise.

So the delivery is **gate precision, not rewrite**: two typed, commented exemptions mirroring the authorizations above, in the 15.4.1 precedent. The `__` exemption is **rule-backed, not prefix-backed** — a class token inside `src/app-shell/**` is sanctioned only when `app-shell.css` defines a matching selector, which keeps the check meaningful and already caught one real finding (`app-shell__footer-locale`, `app-shell.tsx:76`, no rule anywhere). Rejected alternative: pasting the ~37 literals into `allowedClasses` — the debt 14.4.4/14.7.2 already booked twice. Outside `src/app-shell/**`, `__` stays a hard failure; `--` outside a `var(…)` reference stays a hard failure.

**Consequence worth pinning:** no route file (`page`/`loading`/`error`) and no owned primitive is edited, so `frontend-parity:check` and `inventory.json` are untouched by construction. **The `size: L` stamp over-estimates this task** — the epoch fork the card's Log anticipated is not needed; two micro-fronts fit well under the L budget.

2. **Integração:** the principal validates ownership (`pop_check_scope.py`) and the `agent` criteria.

## Riscos e condições de aborto

- **Risco:** an exemption wide enough to hollow out the gate — mitigação: rule-backed (`app-shell.css` selector must exist) and `var(…)`-scoped, both strictly narrower than a prefix allowance; C5 pins what must still fail.
- **Risco:** the footprint was measured by reading, not by running the gate — mitigação: a finding outside the two classes above (a real raw control, adapter import or non-token `--` variant) is **not** rewritten ad hoc; the executor reports it and the principal returns to 002 as `premissa`.
- **Abortar se:** any finding would need a new owned primitive — `inventory.json`'s `owners` is frozen at 20; sinalizar `blocked: true` with the `arquivo:linha` and a proposal.
