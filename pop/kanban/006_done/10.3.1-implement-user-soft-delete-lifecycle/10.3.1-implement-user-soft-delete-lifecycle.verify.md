## Deviations judged

**Declared:** `deletedAt` rides a dedicated `toAdminUserDto` instead of extending `toUserDto` as the plan's wording suggested. **Judgment: accepted — strictly better than the plan.** `Principal = ReturnType<typeof toUserDto>` (`authorization.ts:5`), so extending `toUserDto` would mutate the principal type and force the marker into every identity consumer (~100 call sites) for zero benefit. The deviation delivers the 003-approved admin-DTO contract exactly (`deletedAt` on the administrator directory DTO, pinned by whitelist tests) while keeping principal resolution byte-identical and reducing the R2 leak surface to zero. The plan's intent — admin DTO gains `deletedAt`, principal read unchanged — is fully honored.
