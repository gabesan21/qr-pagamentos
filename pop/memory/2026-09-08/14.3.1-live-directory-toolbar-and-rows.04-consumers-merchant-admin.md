# Eight directories migrated and seven copy files collapsed into one

The five merchant and three administrator directories adopted the contract: `canonicalFilterQuery` for chips, a row href where a detail route exists (never for deleted accounts), and the reset redirect for both page-level and service-level invalid outcomes. The seven near-identical `directory-copy.ts` files were deleted in favour of one shared `dataDirectoryCopy` builder that each page feeds only its own empty title/description. The merchant page-size preference learned the pair so its redirect no longer swallows the notice.
