# Outcome editor, thread and link card

The two `<details>` outcome forms became one wrapper: a select over `LOCAL_FINALIZED`/`LOCAL_CANCELLED`, a note and a `ConfirmDialog` submitting the `set-outcome` POST with its lifecycle version. It is never gated on provider state: the local outcome is a stateless order's whole operator lifecycle. Comments render newest-first through `Timeline`, whose additive `action` slot keeps the author-only CAS edit, beside a `Monogram` composer. The link card resolves the owner's link by identifier, failing closed.
