# 30 primitivos on-soft projetados

Cada papel (`success`/`warning`/`danger`/`info`/`action`) de cada tema ganhou `color.primitive.accessibility.<theme>.<role>-soft-foreground` com hex, componentes e `interpolationStep`, derivado pelo método `k`: origem = hex de auditoria do tom, alvo = `color.text.primary`, fundo único = a superfície soft do mesmo tom, mínimo 4.5:1. Os semânticos `feedback.<tone>.soft-foreground` deixaram de aliasar `text-primary` e nasceu `action.soft-foreground`. Razões de 4.505 a 9.045, nenhuma colapsando em texto primário, nenhum primitivo de auditoria alterado.
