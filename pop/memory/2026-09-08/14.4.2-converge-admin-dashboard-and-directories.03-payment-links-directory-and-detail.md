# Links columns, filters and detail

`admin-payment-links-v2` adds `merchant` and `money` (USD via the active exchange-currency pointer, no pair UUID exposed) — seven filters. Columns become identifier `CopyField`, merchant, amount-or-"N products" and created+expiry. The detail stops hiding the public URL, swaps the destructive alert for the illustrated `EmptyState`, and adds an admin-local associated-orders card reading the orders by `filter.link`. An additive `getForAdminByIdentifier` serves the order detail card.
