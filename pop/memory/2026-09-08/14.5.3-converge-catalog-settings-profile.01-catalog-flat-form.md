# Flat product form and category maintenance

`/catalog` lost its nested cards: one field stack, one submit per page, inline `role="alert"` errors blocking submit, the 14.1.1 draft restore intact. `ImageField` gave way to the owned `ImageUploader` staging to the unchanged image route; the sticky preview shows the selected currency pair and the `product-fallback` asset, reused by list and detail, whose archived badges turned neutral. Create pre-selects the store default currency. Categories gained primitive fields, template dialog labels and an archived-free reference count.
