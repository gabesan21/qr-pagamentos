# Invalid query input became a route, not a card

A page or service that cannot canonicalize URL input no longer renders the destructive card: it issues the existing zero-I/O redirect to its own reset path plus one reserved `filters=ignored` pair, and the reset render raises one informational, echo-free toast with a `<noscript>` fallback. The pair is a redirect artifact, not directory grammar, so every one of the eight resolvers strips it before serializing — that strip is what prevents the loop. The `invalid-query` state stays declared in the specimen and coverage with no production producer.
