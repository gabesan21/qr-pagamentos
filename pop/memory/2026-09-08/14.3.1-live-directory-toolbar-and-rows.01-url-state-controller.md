# The directory toolbar became a URL-state controller

The `<form method="get">` foundation stayed as the no-JS path and the source of the field names; the client shell now commits to the URL: search after a 350 ms debounce, every other control on `change`, each commit rebuilding the canonical query and calling `router.replace` in a transition. A commit reads only `q`, registered `filter.*` and `pageSize`, so `cursor` is dropped by construction and the pending render is the geometry-preserving skeleton. Apply/Reset moved into `<noscript>`, with an inert opt-out for demo surfaces.
