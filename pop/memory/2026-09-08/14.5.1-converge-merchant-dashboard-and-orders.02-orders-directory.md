# Sixth owner filter and template columns

Page sizes, the keyset, cursor inputs, `q` semantics, the `filter.<name>` grammar and the row DTO are unchanged; `directory-query.ts` needed no edit. The page adopted domain badges and a compact link `CopyField`; the V1 ledger became a merchant-local read-only table in the same look.
