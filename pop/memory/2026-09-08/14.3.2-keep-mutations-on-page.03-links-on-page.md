# Payment-link mutations land on the link's own page

Create now redirects to the created link's detail (`/links/v2/<uuid>?payment-links-v2=created`), edit and lifecycle to that same detail, and a failure back to the form that submitted it — create failure to `/links/new`, echoing only an encoded `from`, edit failure to the edit form. Legacy V1 create and revoke stopped landing on `/` and return to `/links` under their own closed key, resolved before strict canonicalization; the dashboard's dead legacy Alert is gone.
