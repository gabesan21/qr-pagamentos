# One controller: state machine, validation, polling

`checkout-experience.tsx` is the controller both era forms adapt: field edits never touch attempt/payment/capability and the explicit start-over is the only reset, re-keying the idempotency key. Its validation module adds e-mail, CPF (server-identical check digits) and CEP checks with masks, numeric `inputMode` and focus to the first bad field; the submit names the exact total by string substitution. Polling keeps the 5s cadence, `1s·2^n` backoff and opaque `404`; only the retry moved to the first failure, and `createPollingController` stayed frozen.
