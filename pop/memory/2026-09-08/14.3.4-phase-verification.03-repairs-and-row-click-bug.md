# The in-phase repairs, and one real bug the suite exposed

Repairs stayed inside the phase's reach: the route param is encoded in both V2 `Location` headers, the uploader's `failed`+`dragOver` pair reaches 4.5:1 in the six themes, and the footer stays mounted while pending. The real defect was the directory row swallowing clicks: `isInteractiveDescendant` was unbounded, so the table's `role="region"` ancestor matched. Bounding it to `event.currentTarget` restores the click, keeps the DOX rule and leaves the keyboard path.
