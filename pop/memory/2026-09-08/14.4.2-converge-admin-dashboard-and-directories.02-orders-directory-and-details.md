# Orders filters, columns and the V1 restyle

`admin-order-v2` registers `state` (eight provider states plus an explicit `STATELESS` mapped to a null column) and `merchant` (exact case-insensitive username equality) — seven filters, inside the cap of eight; keyset, page sizes, `q` and the row DTO are untouched. The page adopts the template column order with domain badges, restores the full source vocabulary, and renders the byte-frozen V1 ledger through an admin-local read-only table, never merged into the keyset page.
