# TOTP challenge as six cells

The single text box became the owned `InputOTP` with six slots, native paste fill and submit on completion, plus a Back link to `/login`. The recovery-code mode kept its 64-character hex format and both modes still post the same `code` field to the unchanged `/login/totp-challenge` route, so nothing about session, challenge validation or the opaque failure copy moved. No lockout state was invented: no attempt counter exists server-side.
