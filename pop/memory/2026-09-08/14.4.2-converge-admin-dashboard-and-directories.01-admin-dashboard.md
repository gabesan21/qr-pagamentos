# Dashboard control, grid and drill-down

The period switcher became a route-local client segmented control over the owned `Tabs`, committing `?period=` with `router.replace` inside a transition; a `<noscript>` fallback and the pinned `7d` server default stay. Orders/sales/funnel moved to `lg:col-span-{5,4,3}` and the whole `.admin-dashboard*` block left `globals.css`; `loading.tsx` renders the real skeleton and `error.tsx` an inline strip whose retry calls `reset()`. Top-merchant rows drill into `/admin/orders?filter.merchant=<username>`.
