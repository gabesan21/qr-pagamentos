# Contracts and the affordances excluded by boundary

The spec records the additive V1 `branding`, the 560px column superseding the two-column widen, and the first-failure retry. Three affordances are excluded, not forgotten: countdown, single-use badge and order reference would each put a link timestamp, the link type or an order id into the pinned DTO/status body, so each needs its own contract change. The no-JS `<form action>` fallback is equally out of reach: the checkout API is JSON-only and `src/app/api/**` was out of scope. `DESIGN.md` and the checkout DOX carry the same record.
