# Order comments and local outcomes stay on the order detail

`POST /orders-v2/[id]` now redirects to `/orders/v2/<id>?orders-v2=<outcome>` on every branch — append, edit, set outcome, unknown action, catch — instead of dropping the merchant on `/orders`. The id is hoisted above the `try` so the failure path uses the same trusted route param. The detail page mounts `OrderV2Notice` over the directory's closed notice set, so a forged value announces nothing, and the comment and outcome forms carry draft guards keyed by order id.
