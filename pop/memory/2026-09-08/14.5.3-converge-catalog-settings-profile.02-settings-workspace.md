# Template store controls over one unchanged save

The store section became a theme swatch grid, a merchant-local layout `SegmentedControl`, a `type="color"` input paired with its hex field and a logo `ImageUploader` reading `logo=<identifier>` from the followed 303 of the unchanged upload route; the native multipart form stays as a sibling `<noscript>` fallback. Store-enabled moved to identity as a `Switch` behind `ConfirmDialog` with a guard naming what is missing, currency gained Clear, and checkout policy became five radio cards posting the same value. One form, one Save.
