# Chips, clickable rows and the template pagination footer

Active filters render as removable chips built from the server's `canonicalFilterQuery`, with each value resolved through the caller's registered enum options — so a raw enum id is never printed. Rows accept an optional server-evaluated `getRowHref` and navigate on row/card click; a click landing on an interactive descendant is ignored, so the explicit action, which stays the keyboard path, keeps working. Pagination moved to the template footer (rows-per-page left, keyset prev/next right), the page-size select bound by `form=`.
