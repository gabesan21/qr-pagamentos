# The first owned upload primitive

`image-uploader.tsx` is a client drop tile covering idle, drag-over, staging, staged (preview/replace/remove), failed with retry and disabled. The caller injects `stage(file)` and gets an opaque identifier, so no route, storage key or revision reaches it. The open target is the native file input in its label, not a nested button. The directed repair moved the input into the replace label with a `has-[:focus-visible]` ring and gave drag-over an icon and solid border, so no state needs color alone.
