# The token check learned the lg breakpoint

The design-token check forbids raw visual values in authored UI files, so the new `@media (min-width: 64rem)` tripped it. One allowlist line maps that literal to `var(--breakpoint-lg)`, the same idiom the script already applies to `900px` and to the shell's `48rem`/`23.4375rem`. `64rem` is exactly the `--breakpoint-lg: 1024px` token at the default root size, and writing the query in `px` would have needed an allowlist line just the same. Authorized by the main agent as an edit outside both fronts' ownership.
