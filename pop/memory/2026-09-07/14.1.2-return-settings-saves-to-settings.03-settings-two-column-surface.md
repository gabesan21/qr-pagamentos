# The settings surface finally styled and de-duplicated

The `settings-surface__*` classes had no CSS at all. `globals.css` gains token-only rules: one column by default, two from `64rem` with a 192px nav column, the nav sticky at `calc(var(--top-bar-height) + var(--space-6))` and the same value as each section's `scroll-margin-block-start`, links at 44px with a `:focus-visible` ring and an active state beyond color. An `IntersectionObserver` sets `aria-current`. Duplicated `CardHeader`s went, notices moved into their section, and the page description became settings copy.
