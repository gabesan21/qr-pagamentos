# Template vocabulary bound in `@theme inline`

`src/app/globals.css` gained 22 new `@theme inline` entries — `bg`, `surface`/`surface-2`, `text`/`text-2`/`text-3`, `accent-fg`/`accent-soft`, `danger`/`info` and the four `*-soft`, `radius-card`/`radius-pill`, `shadow-card`, `font-display`/`font-money`, `container-app`/`checkout`/`auth-form` — each bound to a generated semantic variable, never a literal, so all six themes apply without component branching. `--radius-pill` and `--font-display` repeat the generated names on purpose: Tailwind emits them into `@layer theme`, which the unlayered `:root` outranks.
