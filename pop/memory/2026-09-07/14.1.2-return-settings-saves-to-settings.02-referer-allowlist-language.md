# The language return derived from a closed allowlist

`/language-preference` is also posted by the shell switcher from `/`, so its return cannot be a literal. A new module reads `Referer`, rejects a non-http(s) scheme, checks the host exactly as `origin-guard` checks `Origin` (first `X-Forwarded-Host`, else `Host`), drops query and fragment, and returns one member of the closed set `{ /settings, / }` — anything absent, unparseable, foreign or unlisted falls back to `/`. The output is always a literal, so no `Referer` opens a redirect.
