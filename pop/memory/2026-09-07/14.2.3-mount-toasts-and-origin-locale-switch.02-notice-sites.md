# Notice sites migrated behind `<noscript>`

Catalog products, catalog categories, links, orders and the admin dashboard stopped rendering a visible `Alert` for their query outcomes and now raise a toast, keeping the original `Alert` — same `role` and `variant` — inside `<noscript>`. The directed repair extended the pattern to the two surviving `language` banners on the merchant dashboard and `/settings`, which the global registry would otherwise have duplicated.
