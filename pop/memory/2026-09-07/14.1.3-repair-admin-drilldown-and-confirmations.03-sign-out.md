# The account panel always offers Sign out

The top-bar account panel rendered only a conditional Profile link, so administrators — who receive no profile link — opened an empty menu with no way out. The panel now always renders a `<form action="/logout" method="post">` with a Sign out menu item, keeping Profile conditional; the rail footer and mobile drawer sign-out controls stay as delivered. Styling reuses the existing panel-item rules, with a separator only when Profile precedes it.
