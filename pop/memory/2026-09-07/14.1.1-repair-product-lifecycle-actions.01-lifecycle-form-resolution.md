# Confirmations resolve the real form by id

Both `ConfirmDialog` handlers called `requestSubmit()` on `useRef`s never attached to any element, so archive and activate/deactivate were unreachable. The refs are gone; `submitFormById` resolves `product-active-toggle` and `product-archive` via `document.getElementById` — the mechanism `catalog-submit` and `link-v2-actions` already use, so the catalog has one pattern, not two. Both confirmations still gate their action.
