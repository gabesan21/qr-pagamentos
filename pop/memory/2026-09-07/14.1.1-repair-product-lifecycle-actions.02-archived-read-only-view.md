# Archived products render read-only instead of vanishing

The detail page hid the form once `archivedAt` was stamped, contradicting the terminal read-only archived view the catalog spec pins. `ProductForm` now splits fields from wrapper: under `readOnly` it returns a plain `<div id={formId}>` — no `action="/products"`, no hidden action/id/version, no submit, no state toggle — inside a desaturated surface following the template. No mutation path survives archival.
