# Archived products render read-only instead of vanishing

The detail page hid the form entirely once `archivedAt` was stamped, contradicting the terminal read-only archived view the catalog spec pins. `ProductForm` now splits its fields from its wrapper: in `readOnly` it returns a plain `<div id={formId}>` — no `action="/products"`, no hidden action/id/version inputs, no submit control and no state toggle — rendered inside a desaturated bordered surface that follows the template's `ProductDetailPage`. No mutation path survives archival.
