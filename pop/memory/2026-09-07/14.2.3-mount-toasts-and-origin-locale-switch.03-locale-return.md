# Origin return target and anonymous locale cookie

`resolveSettingsReturnTarget` dropped the closed `{ /settings, / }` allowlist and now returns the host-validated Referer's path plus query, fragment removed, accepted only when it starts with a single `/`; backslash, protocol-relative and foreign-host forms fall back to `/`, and the redirect stays relative. `/language-preference` dropped its blanket `401`: an anonymous caller gets `qr_locale` with the `profile/password` attributes, `qr_session` untouched.
