# Validated theme cookie and root-layout stamping

A new `theme-preference` module owns the `qr_theme` cookie name, a guard
resolving raw values against the resolver-derived id registry, the cookie
builder and a type-exhaustive id→key map. The root layout stamps `data-theme` on `<html>` only for a resolved
principal whose cookie names one of the six ids; anything else stamps nothing
and the `prefers-color-scheme` fallback keeps applying. The
client-writable cookie carries no authorization effect, so it is revalidated
per request, never trusted.
