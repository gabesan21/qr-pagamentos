# Compact language switcher on login and reset

A globe + `PT`/`EN` select for non-shell surfaces now sits in the `CardAction` of both auth pages, posting to `/language-preference` on change — the `requestSubmit` pattern the shell switcher already shipped. It is 44px tall, labelled from `languageLabel`, Tailwind-only because `globals.css` belongs to 14.2.1. Neither page gained a principal read, so both stay opaque; the anonymous cookie makes the choice real.
