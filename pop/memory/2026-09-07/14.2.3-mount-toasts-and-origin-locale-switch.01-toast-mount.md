# Global toast mount and the notice bridge

`ToastViewport` went from zero production call sites to one root-layout mount, labelled from the new `toastRegionLabel` key, so every route reaches it. A closed client bridge takes entries the server already localized, raises one toast, then strips its own params with `history.replaceState` so a refresh never re-toasts. Text always comes from the registry, never from the query value; durations stay the owner's and no motion CSS was added.
