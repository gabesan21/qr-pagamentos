# Drill-down moved to the `filter.link` grammar

The admin link detail emitted `/admin/orders?link=<id>`, which the directory parser rejects, so the drill-down hit the invalid-query card. The href now emits `filter.link=<url-encoded identifier>`, the grammar the merchant link-orders page already uses, resolved by the existing `link` text filter. Only the query string changed.
