# Drill-down moved to the `filter.link` grammar

The administrator link detail emitted `/admin/orders?link=<id>`, a param the directory parser does not accept, so the drill-down landed on the invalid-query card. The href now emits `filter.link=<url-encoded identifier>`, the same grammar the merchant link-orders page already uses, resolved server-side against `paymentLink.identifier` by the existing `link` text filter. No filter, service, or directory contract was added — the defect was the query string alone.
