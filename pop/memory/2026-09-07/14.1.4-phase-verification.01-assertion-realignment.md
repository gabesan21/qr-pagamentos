# Assertions realigned to the targets the phase changed

Eight assertions still encoded the pre-phase behavior: the storefront, checkout-policy and logo routes asserting a `/` or anchorless `Location`, and the admin link detail asserting `?link=`. Each was rewritten to the delivered contract — `/settings?<code>#settings-{identity,policy,store}` and `filter.link` — never deleted. The merchant dashboard case that fed it a `storefront` code was renamed to the `payment-links` code it still handles.
