# Account-menu swatch picker (second client boundary)

The account menu gained a `role="group"` of six `menuitemradio` buttons with
swatch, localized name and a check icon as non-color marker; the handler sets
`<html data-theme>` and writes the cookie, so switching is instant with no
reload. Nothing computes the attribute during render, so
`suppressHydrationWarning` stayed out. Shell props gained an inert
`themeOptions`/`themeMenu` pair, optional so the shell test compiled
unedited; both layouts supply them, reusing the `storefrontTheme*` keys.
