# 10.3.3-build-admin-user-profile-editor — Administrator user profile editor

- **Delivery:** Extended the same `/admin/accounts/[id]` route into the bilingual administrator profile editor for non-deleted users without moving it. The page renders the account facts card plus editor cards for identity (expected-version CAS username/email via `POST /admin/users/[id]/identity`), access (the byte-frozen role/status/password routes re-housed in the editor), locale (`POST /admin/users/[id]/locale`), checkout data policy (`POST /admin/users/[id]/checkout-policy`), and storefront settings (`POST /admin/users/[id]/storefront`), plus a safe store link when the storefront is enabled with a slug and the delivered `POST /admin/users/[id]/delete` form. Deleted users render only the facts card with the localized non-color badge and no editor or delete form. All new POST subroutes run origin-guard first, re-authorize the cookie administrator, and return only empty `401`/`403` or opaque `/admin/accounts/[id]?editor={changed|conflict|failed}` redirects; identity CAS conflicts and storefront slug collisions map to `conflict`, while invalid input, unknown targets, and soft-deleted targets map to `failed`.
