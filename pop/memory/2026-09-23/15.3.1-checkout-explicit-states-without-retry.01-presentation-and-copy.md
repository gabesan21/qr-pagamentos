# Presentation contract and copy (F01)

`CheckoutPaymentView` drops `onRetryPoll`/`pollFailed` for a `statusReadFailed` flag and exports the shared `CheckoutNamedState` composition (title/body/`checkoutStartOver`-only action). Payload-less `PENDING`, `INDETERMINATE`, a rejected QR generation and a failed status read render named states, never pulse or retry; `RESERVED`/`CREATING`/`CREATED` wait with no QR frame. `QrDisplay` gains an additive `onGenerationFailed` callback. Both dictionaries drop every retry key and add matching unavailable/submit-failure keys.
