# Owner payment method and public DTO trim

`OrderV2View` gains a detail-only `paymentMethod` from the attached provider order; summary select and public projections stay byte-identical. Merchant detail renders it bilingually (pt-BR/en) with an explicit absent state. `pixQrCodeUrl` removed from the four public producers: payloads become `{ payment: { state, pixCopyPaste? } }`. The dead prop in `checkout-payment-views.tsx` is left for 15.3.1's rewrite.
