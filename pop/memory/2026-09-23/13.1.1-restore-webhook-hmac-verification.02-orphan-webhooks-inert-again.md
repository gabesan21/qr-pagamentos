# Reset-orphan webhooks become inert again

The restored signature gate is unconditional, so a provider-side orphan webhook left by an owner-initiated registration reset (its secret unknown to the application) now fails HMAC authentication and its deliveries are rejected `401` — the pre-beta inert-orphan guarantee returns as a consequence of the gate, not as a targeted fix. No new code path was added for this; it falls out of removing the beta acceptance branch.

## Evidence

- [[specs/nautt-finance-integration|nautt-finance-integration]] — *"orphan-webhook deliveries" clause, line 26, restored to its pre-beta reading once 13.1.2 removes the trailing caveat*.
