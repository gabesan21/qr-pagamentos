# Controller and adapters (F02)

The shared controller and both route adapters (`public-checkout-v2-form`, `standalone-payment-experience`) drop `retryPoll`/`pollRetryTick`/`pollFailed` and the `1s·2^n` backoff: a failed status read stops the loop and raises `statusReadFailed` instead of rescheduling. Every submit mints a fresh idempotency key; a non-ok/network/malformed submit renders F01's `CheckoutNamedState` submit-failure composition (`checkoutStartOver` only). `startOver` clears the flag too. Tests and evidence specs updated to assert the new machine.
