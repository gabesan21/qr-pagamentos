# Refusal taxonomy and store discard

`pricing-orders-client.ts` gains a closed allowlist of seven documented `code` values on `400`/`422`, raising `NauttOrderCreationRefusedError` (code attached); everything else (network, timeout, 5xx, invalid `201`, undocumented/absent code) stays `NauttOrderCreationIndeterminateError`, unchanged. `owner-pricing-orders.ts` discards the provider-order row on refusal via a new store method and keeps the quote claim, so no second POST is possible on it. Unit tests added; not run (deferred to [[15.2.4-phase-verification]]).
