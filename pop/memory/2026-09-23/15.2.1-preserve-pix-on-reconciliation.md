# 15.2.1 — Preserve PIX on reconciliation

- **Delivery:** `reconcile` in both `ProviderOrderStore` implementations (Prisma, in-memory) now omits `pixCopyPaste`/`pixQrcodeUrl` from the write when the authoritative `GET /orders/{uuid}` read carries no value, instead of nulling them; `completeCreation` is byte-identical to before. New helper `reconcileOrderData` isolates the omission so both stores share one rule.
- **Verification:** non-yolo, single front (F01, `pop-executor`), PR #18 squash-merged into `develop`. Regression tests added in `provider-order-reconciliation.test.ts` and `provider-order-store.test.ts` (42/42 green); suite runs deferred to [[15.2.4-phase-verification]].
- **Contract impact:** one-line invariant added to `pop/specs/nautt-finance-integration.md` (reconciliation section) and `src/integrations/nautt/AGENTS.md`.
