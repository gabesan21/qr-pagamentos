# Suppress public share URL on admin payment-link detail

Gate reparo dirigido: `PaymentLinkV2DetailCard` in `src/app/(merchant)/links/link-v2-views.tsx` gained `showShareUrl?: boolean` (default `true`) so the merchant detail keeps the public `/pay/<identifier>` card while the administrator detail hides it. Added an assertion in the admin page test to lock the boundary.

## Evidência

- [[src/app/(merchant)/links/link-v2-views.tsx|link-v2-views.tsx]] — conditional Share URL card.
- [[src/app/admin/payment-links/v2/[id]/page.tsx|admin/payment-links/v2/[id]/page.tsx]] — passes `showShareUrl={false}`.
- [[src/app/admin/payment-links/v2/[id]/page.test.tsx|page.test.tsx]] — asserts no `sharePath` in admin markup.
