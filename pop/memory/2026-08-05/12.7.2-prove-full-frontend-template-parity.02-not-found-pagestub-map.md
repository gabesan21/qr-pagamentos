# Mapeamento do `PageStub` `*` para `src/app/not-found.tsx`

Criado `src/app/not-found.tsx` para mapear a rota catch-all `*` do template (`PageStub.tsx`), mantendo as classes de apresentação do stub. O script de parity foi estendido para vincular automaticamente `PageStub` a `src/app/not-found.tsx` quando a rota template for `*` e o componente existir.

- [[src/app/not-found.tsx]] — *página 404 com classes do PageStub*.
- [[docs/template/app/src/pages/PageStub.tsx]] — *stub original*.
- [[scripts/check-frontend-template-parity-contract.mjs]] — *mapeamento automático `*` → `not-found.tsx`*.
