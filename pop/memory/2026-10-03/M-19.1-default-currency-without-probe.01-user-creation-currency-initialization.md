# Inicialização de moeda na criação de usuário

Novos usuários com perfil `USER` recebem automaticamente o código da moeda padrão ativa do sistema (`BRL` prioritário ou primeira mapeada por ordem de código) no campo `storefrontDefaultCurrencyCode`, com fallback para `null` caso nenhuma moeda esteja ativa. Perfis `ADMIN` mantêm `null`.

## Evidência

- [[src/auth/administration.ts]] — *resolução e persistência de storefrontDefaultCurrencyCode em createUser*.
- [[src/auth/administration.test.ts]] — *cobertura de atribuição automática na criação*.
